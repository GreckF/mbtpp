# #mbt Functions

Functions can be marked `#mbt` too: each is compiled to a public MoonBit function of the same name, which MoonBit code can call directly.

```moonbit
#mbt
enum Tree[T] {
  Leaf
  Node(Tree[T], T, Tree[T])
}

#mbt
fn[T] insert(t : Tree[T], x : T, lt~ : (T, T) -> Bool) -> Tree[T] {
  match t {
    Leaf => Node(Leaf, x, Leaf)
    Node(l, y, r) =>
      if lt(x, y) {
        Node(insert(l, x, lt~), y, r)
      } else {
        Node(l, y, insert(r, x, lt~))
      }
  }
}

#mbt
fn[T] Tree::depth(self : Tree[T]) -> Int {
  match self {
    Leaf => 0
    Node(l, _, r) => {
      let a = l.depth()
      let b = r.depth()
      1 + (if a > b { a } else { b })
    }
  }
}

fn main {
  let mut t : Tree[Int] = Leaf
  for i = 0; i < 6; i = i + 1 {
    t = insert(t, i * 7 % 10, lt=(a, b) => a < b)
  }
  println(t.depth())
}
```

The output:

```text
pub fn[T0] insert(t : Tree[T0], x : T0, lt~ : (T0, T0) -> Bool raise) -> Tree[T0]
pub fn[T0] Tree::depth(self : Tree[T0]) -> Int32
```

(`moon fmt` writes MoonBit's `Int` as `Int32`.)

## Signature (checked during type checking)

- Implicit parameters can only be type parameters `[T]`; bounds can only be `#mbt` traits on type parameters, and a bounded type parameter must appear in
  the parameters or the result.
- Parameters and results are MoonBit types; proof parameters (whose type is a proposition) are
  erased and do not appear in the MoonBit function.
- `x~` and `x?` parameters are supported; default values are not.
- Methods can only belong to `#mbt` types generated by this program.
- `main` cannot be marked `#mbt`.
- `#mbt("name")` sets the function's name in MoonBit.

## Body (checked during compilation)

The body must be in the native fragment; otherwise compilation fails and points to the first expression that cannot be natively translated, for example:

```text
#mbt fn f cannot be compiled to MoonBit: its body is not in the native fragment:
in `println(x)`, println has no native signature (a type without a MoonBit type,
or a bound that is not #mbt)
```

## raise

A function that does not declare `raise` does not `raise` in MoonBit either; runtime failures inside it (such as an incomplete match) become
`abort`. A function that declares `raise E` is `raise` in MoonBit.
