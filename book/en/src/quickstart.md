# Quick Start

After installing `moonpp` (see [Installation](moonpp/install.md)):

```bash
moonpp new hello
cd hello
moonpp run                # run src/main with the interpreter
moonpp check              # type check
moonpp run --compiled     # compile to MoonBit, then run
moonpp build              # compile into the MoonBit project mbtpp_out/main
```

The `src/main/main.mbtpp` generated by `moonpp new` looks like this:

```moonbit
enum Vector[T] : Nat -> Type {
  Nil : Vector[T](0)
  Cons[n : Nat](T, Vector[T](n)) : Vector[T](S(n))
}

// Accepts only non-empty vectors: no Nil branch needed
fn[T, n : Nat] Vector::head(self : Vector[T](S(n))) -> T {
  match self {
    Cons(x, _) => x
  }
}

fn main {
  let v : Vector[String](2) = Cons("Hello", Cons("MoonBit++", Nil))
  println(v.head())
}
```

- `Vector[T](n)` is a vector of length `n`: `T` is a parameter and `n` is an index (see
  [enum and indexed types](lang/enum.md)).
- `head` only accepts vectors of type `Vector[T](S(n))`, so `Nil` cannot occur and the `match` needs no branch for it
  (see [Coverage checking and impossible branches](lang/coverage.md)).
- `v.head()` calls the method `Vector::head`.

You can also try it without installing anything in the [Playground](https://greckf.github.io/mbtpp/).
