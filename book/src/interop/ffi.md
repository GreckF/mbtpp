# 调用 MoonBit 函数

编译后的程序真正调用导入的 MoonBit 函数：

- **从原生代码调用**：直接调用，不做转换。
- **从统一表示调用**：按签名转换参数和结果。

支持的签名：

| 类型 | 转换 |
| --- | --- |
| `Int`、`Double`、`Bool`、`Char`、`String`、`Unit` | 标量 |
| 类型参数 | 不转换（值本身） |
| `Array[T]`、`T?` | 逐元素 |
| `#mbt` 数据类型（包括导入的 `pub(all)` 类型） | 逐构造子 |
| 函数类型 | 回调：MoonBit 调用时转换参数和结果 |
| 不透明类型 | 装箱 |
| 带标签参数、可选参数、`raise` | 支持 |
| 带 `#mbt` trait 约束的泛型函数 | 从原生代码调用 |

- 签名不受支持的外部函数如果被调用，是**编译错误**，并说明原因。
- **只读类型**（`pub` 而不是 `pub(all)`）的值不能从统一表示重建，只能在原生代码中传递。在
  统一表示中把它们交给 MoonBit 函数会报编译错误，提示改为在原生片段中调用。
